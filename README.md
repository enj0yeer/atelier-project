# Информационно-справочная система швейного ателье

Учебный веб-проект, разработанный в рамках курсовой работы по дисциплине «Современные технологии программирования». 
Приложение представляет собой информационно-справочную систему для автоматизации учета клиентов, услуг и заказов швейного ателье.

## 1. Технологический стек
* **Язык:** Java 17
* **Фреймворк:** Spring Boot 3.2.12
* **Безопасность:** Spring Security 6 (BCrypt, CSRF)
* **База данных:** PostgreSQL 15, Spring Data JPA, Hibernate 6
* **Frontend:** Thymeleaf, HTML5, CSS3, JavaScript (Chart.js)
* **Сборка:** Apache Maven + Maven Wrapper

## 2. Функциональные модули
* **Аутентификация и авторизация:** регистрация, вход по email, роли (CLIENT, MASTER, ADMIN).
* **Каталог услуг:** просмотр, добавление, редактирование и скрытие услуг.
* **Заказы:** создание с серверным расчетом стоимости, фильтрация, контроль допустимых переходов статусов (NEW -> IN_PROGRESS -> READY -> ISSUED).
* **Статистика:** графики по статусам и суммам заказов.
* **Управление пользователями:** смена ролей с защитой от изменения собственной роли.

## 3. Инструкция по развертыванию
### Предварительные требования:
Установленная Java 17 (JDK) и PostgreSQL 15.

### Шаг 1. Подготовка БД
Выполните скрипт `sql/00_create_database.psql` в psql или pgAdmin. Он создаст пользователя `atelier`, базу `atelier_db` и все таблицы.

### Шаг 2. Запуск приложения
Проект поддерживает Maven Wrapper (Maven устанавливать не нужно).
* **Windows:** `mvnw.cmd spring-boot:run`
* **Mac/Linux:** `./mvnw spring-boot:run`
* **Через IDEA:** Откройте `AtelierApplication.java` и нажмите Run.

### Шаг 3. Доступ
Сайт будет доступен по адресу: **http://localhost:8080**

## 4. Тестовые учетные записи
| Роль | Логин | Пароль |

## 5. Альтернативный запуск (Docker)
Если установлен Docker Desktop, в терминале можно выполнить `docker compose up -d` для автоматического развертывания PostgreSQL.
