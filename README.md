# Информационно-справочная система швейного ателье

Учебный веб-проект, разработанный в рамках курсовой работы по дисциплине «Современные технологии программирования». 
Приложение представляет собой информационно-справочную систему для автоматизации учета клиентов, услуг и заказов швейного ателье.

## 1. Технологический стек
* **Язык:** Java 17
* **Фреймворк:** Spring Boot 3.2.12
* **Безопасность:** Spring Security 6 (BCrypt, CSRF)
* **База данных:** PostgreSQL 15, Spring Data JPA, Hibernate 6
* **Frontend:** Thymeleaf, HTML5, CSS3, JavaScript (Chart.js)
* **Сборка:** Apache Maven

В проекте закреплена Spring Boot `3.2.12` как версия учебной работы. Для дальнейшего сопровождения или реального развёртывания запланируйте переход на поддерживаемую ветку Spring Boot; перед обновлением нужно прогнать тесты и проверить совместимость зависимостей.

## 2. Функциональные модули
* **Аутентификация и авторизация:** регистрация, вход по email, роли (CLIENT, MASTER, ADMIN), ограничение доступа к функциям по роли.
* **Каталог услуг:** просмотр, добавление, редактирование и скрытие услуг.
* **Заказы:** создание с серверным расчетом стоимости, фильтрация, контроль допустимых переходов статусов (NEW -> IN_PROGRESS -> READY -> ISSUED).
* **Статистика:** графики по статусам и суммам заказов.
* **Управление пользователями:** смена ролей и удаление аккаунтов; нельзя удалить собственный аккаунт, последнего администратора или пользователя, чьи заказы должны остаться в истории.
* **Главная страница:** краткое описание ателье, карточки услуг и переходы к каталогу и регистрации.

## 3. Запуск локально

Требуются JDK 17 и Docker Desktop. Maven Wrapper входит в репозиторий, поэтому отдельно устанавливать Maven не нужно.

Для установки используйте официальные страницы: [Docker Desktop для Windows](https://docs.docker.com/desktop/setup/install/windows-install/) и [Eclipse Temurin JDK 17](https://adoptium.net/temurin/releases/?version=17). В установщике JDK включите добавление Java в `PATH` и настройку `JAVA_HOME`. После установки проверьте `java -version` и `docker version`.

1. Запустите PostgreSQL в Docker: `docker compose up -d`.
2. Соберите и запустите приложение: Windows `mvnw.cmd spring-boot:run`, macOS/Linux `./mvnw spring-boot:run`.
3. Откройте **http://localhost:8080**.

Compose публикует PostgreSQL на порту `5433` хоста (в контейнере он слушает `5432`). Приложение по умолчанию подключается к `localhost:5433`. Если порт или учётные данные меняются, задайте одинаковые переменные `DB_URL`, `DB_USERNAME` и `DB_PASSWORD` для приложения; `DB_PASSWORD` при первом создании контейнера также используется PostgreSQL. Уже созданный Docker volume сохраняет пароль и данные при пересоздании контейнера.

В IntelliJ IDEA импортируйте проект как Maven-проект, выберите JDK 17 и запустите `ru.fa.atelier.AtelierApplication`.

## 4. Проверка

Запуск тестов: Windows `mvnw.cmd test`, macOS/Linux `./mvnw test`. Интеграционный тест репозитория использует H2 и не требует PostgreSQL; веб-тесты проверяют ограничения доступа Spring Security.

## 5. Правило назначения мастера

Новый заказ создаётся без назначенного мастера. Активный мастер закрепляет за собой свободный заказ, когда переводит его из `NEW` в `IN_PROGRESS`. После назначения другой мастер не может менять статусы этого заказа. Администратор может менять статусы без автоматического назначения себя исполнителем.

## 7. Схема базы

При запуске Hibernate обновляет схему (`spring.jpa.hibernate.ddl-auto=update`). SQL-скрипты в `sql/` создают таблицы и каталог услуг. Связанные с учётными записями демо-клиент, мастер и пример заказа создаются `DataInitializer` при старте приложения. Скрипт `00_create_database.psql` предназначен для новой базы; не запускайте его повторно поверх рабочей базы без предварительной проверки.
